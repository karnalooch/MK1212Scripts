# Security policy

This repository contains mod scripts/data and repository automation. It must not contain passwords, tokens, private keys, game-account credentials or redistributed proprietary game binaries.

For a security-sensitive report, use GitHub private security reporting when available or contact the repository owner privately. Do not publish exploit details or credentials in a public pull request.

Repository automation follows least-privilege permissions and immutable external action/workflow pins. A missing required security check is a failure or blocker, not an implicit pass.
